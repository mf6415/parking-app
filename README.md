# 駐輪場管理アプリ(試作)

小規模な駐輪場向けの、月極契約者管理・入金記録アプリです。
iPad / iPhone のホーム画面に追加して、アプリのように使えます。

## 料金の考え方

契約期間は **1日から月末まで** です。月の途中から契約した場合、その月だけ日割りになります。

| 区分 | 月額 |
| --- | --- |
| 学生 | 2,000円 |
| 社会人 | 2,500円 |
| 日割り | 当月停める日数 × 100円(月額を上限とする) |
| 一時利用 | 1回 100円 |

日割りが月額を上回る場合は月額で止まります。たとえば学生が10日から月末まで(21日間)
利用した場合、21×100=2,100円ではなく月額の2,000円になります。
金額は設定画面から変更できます。

## できること

- **ホーム** — 今月の契約数、入金済み金額、未入金金額、本日の一時利用をひと目で確認。
  未入金の方の一覧から、その場で入金を記録できます。
- **更新のお知らせ** — 月末が10日以内に迫ると、翌月分がまだ入金されていない方をホームに表示します。
  その場で翌月分の入金も記録できます。
- **契約者** — お名前、区画番号、区分(学生/社会人)、月額料金、電話番号、契約開始日、車種メモを
  登録・編集・削除。月額を空欄にすると区分の料金が使われます。解約済みの方は一覧の下に薄く表示されます。
- **まとめて追加** — 名簿を貼り付けるか CSV を読み込むことで、何人分でも一度に登録できます。
  カンマ区切り・タブ区切り(Excelからの貼り付け)・全角文字・見出し行・区分の列の混在に対応し、
  追加前に読み取り結果を一覧で確認できます。Excel が作る Shift-JIS の CSV も自動判別します。
- **入金** — 月を切り替えながら、名前の横のボタンをタップして入金済み・未入金を記録。
  日割りの月はその旨と日数が表示されます。過去の月もさかのぼれます。
- **一時利用** — 日ごとに受付を記録します。入庫時刻・出庫時刻・料金に加え、
  車体の色、カゴの有無、年代、性別を選択式で残せます。すべて未選択のままでも構いません。
  閉店時に「まだ残っている自転車」が何台かも分かります。

  | 項目 | 選択肢 |
  | --- | --- |
  | 色 | シルバー / ピンク / 黒 / 茶色 / 緑 / 黄緑 / 水色 / 紫 / その他 |
  | カゴ | あり(前) / あり(後) / あり(前後) / なし |
  | 年代 | 30代 / 40代 / 50代 / 60代 / 70代 / 80代 |
  | 性別 | 男 / 女 |
- **売上** — 年を切り替えて、月ごとの月極収入と一時利用収入、年間合計を確認できます。
  確定申告用に、1件ごとの明細CSVと月別集計CSVを書き出せます。
- **設定** — 駐輪場の名前、料金(学生・社会人・1日あたり)の変更と、データのバックアップ書き出し・復元。

駐輪場の名前は設定画面から入力する方式にしており、プログラム側には書き込んでいません。
施設名や所在地がこのリポジトリから分かることはありません。

## データの保存場所について

データは **使っている端末のブラウザの中だけ** に保存されます。外部のサーバーには一切送信されません。

そのため、次の点に注意してください。

- iPadで入力したデータは、iPhoneやパソコンには出てきません(端末ごとに別々)。
- 端末の故障・買い替え・Safariの履歴一括削除でデータが消えることがあります。
- **定期的に「設定」タブからバックアップを保存してください。**
  iPad では共有メニューが開くので、そこから Google ドライブを選べます。
  パソコンのブラウザでは通常のダウンロードになります。
- 前回のバックアップからの経過日数が設定画面に表示され、30日を過ぎると赤く警告します。

## 動作環境

iOS / iPadOS 15.4 以降の Safari を想定しています。パソコンの Chrome や Edge でも動きます。

## 開発メモ

外部ライブラリを一切使わない、HTML・CSS・JavaScript のみの構成です。ビルド作業は不要で、
`index.html` をブラウザで開けばそのまま動きます。

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体。画面・処理・見た目がすべてこの中に入っています |
| `manifest.json` | ホーム画面に追加したときの名前やアイコンの設定 |
| `icon-180.png` | ホーム画面用アイコン |
| `icon-512.png` | 大きいサイズ用アイコン |
